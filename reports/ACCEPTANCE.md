# Acceptance against the brief (1.0.0-rc4)

Each of the 34 release blockers in section 21 of the brief, with the evidence. **Met** means it works in the standalone program and an automated test or the end-to-end test exercised it. **Partly** means it works but part of it was not tested or is missing. **Not met** means it does not yet hold.

Test evidence (all in this repository):

- `tests/run_app_tests.sh`: five headless suites (app core 87, editor 107, projects and import 146, modules 57, online library 22: 419 checks) and a smoke tour of the whole program. The online suite runs against a local stand-in for Poly Haven that also limits requests (HTTP 429), drops connections and redirects; the project suite reads a `.blend` file with Ubuntu's Blender 4.0.2 and, when that Blender fails, with the built-in engine. With `GENESIS_PLUGIN_PROJECT` set to a clone of the original Genesis repository, the project suite also brings that repository in as an old plugin project (3 more checks).
- `tools/build_standalone.sh`: the exported Linux program's own smoke tour, with the bundled library and the material presets.
- `reports/E2E_RESULTS_build.md`, `E2E_RESULTS_verify.md`, `E2E_RESULTS_views.md`, `E2E_RESULTS_media.md`, `E2E_RESULTS_walk.md`, `E2E_RESULTS_photoreal.md`: the end-to-end test of section 16, and of Eevee and Cycles, in **six separate launches of the rc4 AppImage itself** (mounted with FUSE, as on a desktop), on an empty user profile, with Godot's Forward+ renderer on Mesa's software Vulkan, Eevee on Mesa's software OpenGL and Cycles on the processor (no GPU on the build machine): 63 steps passed, 1 could not be tested here (5b, the live OpenStreetMap services), 0 failed. Each launch ended with exit code 0 (build exit 0 (attempt 1, 78 s); verify exit 0 (attempt 1, 364 s); views exit 0 (attempt 1, 1457 s); media exit 0 (attempt 1, 1030 s); walk exit 0 (attempt 1, 209 s); photoreal exit 0 (attempt 1, 1014 s)). The build machine was restarted (by its host, with a new system version) a minute into the *media* launch; the run was carried on from that launch with the same project and profile, as the launches are separate anyway. Screenshots, renders, the virtual tour and the films: `reports/e2e_screenshots/`.
- The original plugin's `selftest` suite, still passing with the plugin running through the new host layer.
- The AppImage itself, run on an empty user profile (see 34), and a screenshot tour of every page and dialog from it (`--ui-tour`).
