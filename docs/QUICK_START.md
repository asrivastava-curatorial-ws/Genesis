# Quick start

To look around before making anything, open one of the two demo projects in the release's `demos/` folder with *Open Project…*.

1. **Start Genesis** (`Genesis.sh` or `Genesis.bat`). The project manager opens.
2. **New Project…** Give it a name and a folder. It opens with a sun, sky and ground already in.
3. **Bring in a building**: File > Bring In a Model… (Ctrl+I), or drop a `.glb`, `.gltf`, `.fbx`, `.obj` or `.blend` file on the window. Say what unit it was made in and which way is up.
4. **Look around**: middle-drag orbits, Shift + middle-drag pans, the wheel zooms. On a laptop: Alt + left-drag orbits. F frames what is selected; Home frames everything.
5. **Arrange**: click to select, then drag the arrows (move), rings (E: turn) or boxes (R: resize). Ctrl snaps. Every change can be undone (Ctrl+Z).
6. **Dress it**: the Genesis panel on the right has the sections in working order: Plans, Assets, Environment, Landscape, Set, Materials.
7. **Frame shots**: Cameras > save the view; Look gives it a finish.
8. **Render**: Render > choose a camera, a size and a quality. Pictures go to the project's `renders/` folder.
9. **Save**: Ctrl+S. Genesis also keeps unsaved work every few minutes and the last five saved versions in `backups/`.

Help > Keyboard and Mouse (F1) lists every shortcut.
