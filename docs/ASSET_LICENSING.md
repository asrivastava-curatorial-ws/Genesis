# Asset licensing

Every model Oriel ships carries a licence record (`<model>.license.json`) beside it. The library lists a model only if that record exists, so nothing of unknown origin can reach a render. This page is generated from those records by `tools/make_notices.py`; the records are the authority.

## Summary

- **295 models**, all **CC0-1.0** (public domain dedication). No attribution is required for any of them.
- Models were generated by the Oriel project's own Blender scripts in `tools/blender/`; people are built from MakeHuman CC0 assets (via MPFB).
- Where a model's surfaces use photographic textures, they are CC0 scans from ambientCG; each record lists them under `surfaces` (12 distinct texture sources).
- Downloaded at setup, not shipped in the repository: HDRI skies (Poly Haven, CC0), scanned materials (ambientCG, CC0), leaf and bark atlases for the plant library (CC0). `tools/fetch_assets.py` writes a `.license.json` beside each.
- Site context comes from OpenStreetMap at run time and is **ODbL**: renders that show it must credit "© OpenStreetMap contributors". Terrain tiles (Mapzen/AWS Open Data) and USGS imagery are public domain; Sentinel-2 imagery is from the Copernicus programme (free, with attribution: "Contains modified Copernicus Sentinel data").
